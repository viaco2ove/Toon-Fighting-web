# 悬浮头像
沿用toonflow-field-survival 在实体头上挂个悬浮头像的低成本做法
```
  function layoutHeadAvatars() {
    if (!settings.battle.headAvatar) { headavEl.classList.remove('on'); headavEl.innerHTML = ''; headNodes = {}; return; }
    const p1 = headPos[1], p2 = headPos[2];
    if (!p1 && !p2) { headavEl.classList.remove('on'); return; }
    const sc = headScale();
    headavEl.classList.add('on');
    for (const side of [1, 2]) {
      const pos = headPos[side];
      const node = headNodes[side];
      if (!pos || !node) continue;
      const x = sc.ox + pos.x * sc.sx;
      const y = sc.oy + pos.y * sc.sy;
      // 头顶位置：角色轴点（≈脚底）往上抬。精灵高度带透明边距不可信（实测
      // Hinako 站立 sprH=126、实际只画出 ~70 游戏像素），改用固定抬升。
      // 实测本池角色身高 70~100 游戏像素（320×240 下）。
      // 注：.ha 有 translate(-50%,-100%)，style.top 是**渲染盒的底边**；
      // 盒内只有一个 46px 白边方块（无名字条），方块底 = top。
      // 抬升 148 → 方块底 ≈ 轴点上 148 游戏像素（2026-11-28 用户要求「再高一个头像那么高」，
      // 原 102 + 一个头像位 46）：
      // 高个（Lin/Rugal ≈100）方块搭在发顶，矮个（Hinako ≈70）上浮 ~30 像素。
      const liftPx = 148 * sc.sy;   // 2026-11-28 用户要求再抬一个头像位（102 + 46）
      node.style.left = x.toFixed(1) + 'px';
      node.style.top = (y - liftPx).toFixed(1) + 'px';
    }
```
