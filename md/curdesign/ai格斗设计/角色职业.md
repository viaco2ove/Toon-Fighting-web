# 角色职业表（ai 格斗联动 · 分配池设计）

> 上游：[ai格斗联动-总体设计.md](./ai格斗联动-总体设计.md) §4 / [资产集 tbg 子设计](./资产集/README.md)
> 作用：定义「末世选择」世界观下的角色职业维度，用于联动面板角色分配池（≤6 上场）与 tbg 资产集 `roster.json`/`mapping.json` 的 charPool 扩充选型。

## 1. 设计原则

1. **职业 ≠ 引擎角色**。职业是故事侧标签（AI 剧情 NPC 该以什么战斗风格出场），引擎角色是执行体；一个职业可映射多个引擎角色，一个引擎角色可兼职多个职业。
2. **charPool ≤ 本地已装集合**（资产集安装器求交集），所以本表每职业都给出「现有 / 可下载」两档。
3. **可下载角色只做 WinMUGEN 兼容档**（含完整 sff/cns/snd，模板风格与现有 Lin/Rugal2nd/Hinako 一致），避免 1.0-only/HD 重制版踩 IKEMEN-GO 兼容坑；入库流程：解压进 `ikemen-fs/file/chars/<id>/` → 跑 `.cache/scripts/patch-char-ai.mjs` → 重建 manifest → `verify-story.mjs` 全链验证。
4. **版权红线不变**：仓库/资产集只存角色名引用与文案，资产本体由用户按来源自行下载（见 §3 来源清单）。

## 4. 首批扩充执行清单（建议顺序）

1. **军人位：Leona**（2 个来源已验证，风格/体型与现池最搭）→ 下载 → 入库四步流程 → `tf_fight_roster` 加一名军人 NPC 映射。
2. **异能位：Kula**（冰属性与 K' 火焰对仗，末世氛围强）。
3. **武道位：Ryo（坂崎亮）** 或补全版 Kim。
4. **黑帮位：山崎龙二**（废墟头目高频 NPC）。
5. 第二批（Maxima / Mary / Raiden / Eiji）等 M4 资产集跑通后再扩。

## 5. 开放问题

- 联动面板当前从**会话消息**提取角色（roleType/出场次数），职业标签将来从哪来：a) AI 生图 agent 的 prompt 附带；b) tbg `roster.json` 的 `desc` 字段人工标注；c) 两者合并。倾向 b+c（详见 M4/M5 设计）。
- Boss 位角色（Orochi 系）体积与 AI 强度远超普通 NPC，引入前需单独评估 `-p2.ai` 上限与 `time/rounds` 参数。
