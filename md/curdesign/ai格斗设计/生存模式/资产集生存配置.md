# 资产集生存模式配置（survival.json）

资产集根目录放 `survival.json` 即可让生存模式按资产集设定运行（设计来源：`生存模式.md` 的三条：
①多少局/无限 ②每局对手/随机 + 开场白/胜负旁白 ③小/中/最终 Boss）。没有此文件的资产集 =
纯随机对手 + AI 逐关递增（默认行为，完全兼容）。

文件编码 UTF-8。手机/PC 都从资产集根直接读取（`FFDecode.fetchPackText`）。

## Schema

```jsonc
{
  "name": "显示名",
  "desc": "一句话说明",
  "rounds": "infinite",          // ① "infinite" 无限局，或数字（打满 N 关即全通关结算）
  "ai": { "start": 1, "step": 1, "max": 8 },   // AI 随关数递增：start + step*(关-1)，封顶 max
  "pool": ["CharA", "CharB"],    // 随机关的对手限定名单（角色目录名）；缺省 = 资产集全角色
  "defaultNarration": {          // 随机关的旁白池（每类随机取一条）
    "intro": ["开场白…"],
    "win":  ["胜利旁白…"],
    "lose": ["失败旁白…"]
  },
  "stages": {                    // 指定普通关（覆盖随机）；char 可指定对手，intro/win/lose 覆盖旁白
    "1": { "intro": "第 1 关开场白…" },
    "4": { "char": "CharB", "intro": "…" }
  },
  "bosses": {                    // ③ 小/中/最终 Boss（命中关数时覆盖一切，含 ai）
    "mini":  { "stage": 3, "char": "CharC", "title": "小 BOSS · xx", "ai": 3,
               "intro": "Boss 登场白", "win": "胜利旁白", "lose": "失败旁白" },
    "mid":   { "stage": 6, "char": "CharD", "title": "中 BOSS · xx", "ai": 5, "…": "…" },
    "final": { "stage": 9, "char": "CharE", "title": "最终 BOSS · xx", "ai": 7, "…": "…" }
  }
}
```

## 前端消费点（index.html）

| 配置 | 消费位置 |
|---|---|
| `bosses/stages[].char` | 选人屏对手区（`survDisplayChar`）+ 开局实体（`resolveSlots`，`survivalOpponent`） |
| `bosses[].title` | 对手栏标题（`p2cap`：`对手 · 第 N 关 · 小 BOSS · xx`）与面板名 |
| `bosses[].ai` / `ai` | 开局 AI（`survAiNow`：Boss 覆盖 > start+step*(关-1) 封顶 max） |
| `rounds`（数字） | 胜利后打满 N 关 → 「已通关全部 N 关」结算并回主界面 |
| `intro/win/lose` 旁白 | 开场白走 `showSpeech('p2', …)`；胜负旁白进结算大字（`showResult`） |
| `pool` | 随机关对手限定名单（不在名单里的角色不会随机到） |

## 优先级

Boss（mini/mid/final 命中关数）> `stages["N"]` > 随机（`pool` 限定）。
旁白：Boss > stages > defaultNarration 随机一条 > 前端默认文案。

## 末世选择包（moshi-v1）的设定

- 无限局；AI 1 起步、每关 +1、封顶 8；
- 第 3 关 小 BOSS 老雷（LaoLeiKFM，AI 3）；第 6 关 中 BOSS 甄选使（ZhenXuanshiKFM，AI 5）；
  第 9 关 最终 BOSS 神选者（Rugal2nd，AI 7）；之后无限随机；
- 随机池 = 12 个有玩家接线的角色（AI 打法包不进池——它们不会反抗）；
- Boss 选角依据：只有「有玩家接线的角色」才能当 Boss（接线矩阵见
  `.zcode/skills/analyze-pad-buttons`）。
