# 资产制作（ai 格斗联动 · 入库与映射制作流程）

> 上游：[角色职业.md](../角色职业.md)（选什么角色）、[下载源.md](./下载源.md)（去哪下载）
> 本文回答：**拿到一个 MUGEN 角色包之后，怎么做成能跑、能进分配池、能进资产集的资产**。
> 全流程已在 Leona（KOFA 版）入库时实测走通（2026-11-24），以下命令与判据均为实证口径。

## 0. 总览：一条角色从下载到可用

```
下载 zip → 解压进 ikemen-fs/file/chars/<id>/ → def 规范化 + 野 AI 检查
→ select.def 注册 → 重建 manifest.json → 验证脚本双阶段跑绿 → 资产集映射登记
```

只缺其中一步的典型症状：
- 忘重建 manifest → 「代码明明改了，引擎行为一点没变」（静默加载旧文件）
- 忘跑 AI 闸补丁 → 练习模式（ai=0）的「人类」角色自己动起来打人
- 忘注册 select.def → 引擎报 character not found

## 1. 角色包验收判据（下载后先查这个）

WinMUGEN 兼容档必须**四件套齐全**，缺任何一件角色跑不起来：

| 文件 | 作用 | 缺失后果 |
|------|------|---------|
| `<name>.def` | 角色入口定义 | 无法加载 |
| `<name>.sff` | 立绘/动作贴图包 | 黑块/直接崩（现库 98-kim、MasterRyu 就是缺 sff 的反面教材） |
| `<name>.cns`/`.st` | 状态控制器（招式逻辑） | 无招式 |
| `<name>.air` | 动画帧定义 | 动作错乱 |
| `<name>.snd` | 音效 | 可缺，能跑但哑 |

附加判据：
1. **版本口径**：选 WinMUGEN 兼容档（与现库 Lin/Rugal2nd/Hinako 同模板风格）。1.0-only / HD 重制版在 IKEMEN-GO 有未验证的兼容坑（mugen 版本参数、缩放、palette 行为都可能变），不要首选。
2. **体积合理**：完整单角色 zip 通常 3–25MB（Leona 4.6MB、AK1 版 Leona 21.3MB）。几十 KB 的「精简包」基本是缺件。
3. **野 AI 检查**（决定要不要打 AI 闸）：搜 cns 里的 `var(59)`：
   - 只有 `var(59) := 0` 置零分支、没有置 1 语句 → 天然惰性，**免打 AI 闸**（KOFA 版 Leona 属此类）
   - 有 `RoundState=2 && 敌人活着 → var(59):=1` 这类块 → 必须打 AI 闸，见 §2.3

## 2. 入库流程（四步）

### 2.1 解压与 def 规范化

```powershell
# 解压进 chars/<id>/，id 用 ASCII 原名（引擎 argv 引用这个名字）
Expand-Archive leona-kofa.zip -DestinationPath ikemen-fs\file\chars\Leona
```

- 目录名 = `chars/` 下的目录 id，保持与 zip 内 def 名一致最省事；def 与目录不同名时把 def 改名成目录名（`Leona.def`），避免 select.def 引用歧义。
- zip 内若带 `*.bak`、readme、多余 pal 备份不必删——manifest 本就不收录 `*.bak*`。
- 现库角色 id 一律大小写敏感：`Lin`、`Hinako`、`K'`（注意带撇号，argv 与 select.def 引用时都要原样）。

### 2.2 select.def 注册

`ikemen-fs/file/data/select.def` 的 `[Characters]` 段加一行（Leona 实例）：

```ini
[Characters]
Leona            ; 已入库 2026-11-24 KOFA 版
```

- 不需要写 stage 后缀，默认随机舞台。
- 随机格（`randomselect`）会自动把新角色纳入「?」池，前端选人的「?」按钮跟着生效。

### 2.3 野 AI 闸（按 §1 判据 3 决定）

需要打闸时跑补丁脚本（给 AI Start 块加 `TriggerAll = Ailevel > 0`，带 `;[toon]` 注释）：

```
node .cache/scripts/patch-char-ai.mjs
```

- 脚本按角色名匹配，**新角色包入库后跑一遍**；跑完确认 cns 里出现 `[toon]` 注释行。
- 原理见 AGENTS.md 机制 2：AI 闸必须让 `var(59)=1` 的分支在 `Ailevel=0`（练习/人控）时不触发，正式对战（Ailevel>0）不受影响。

### 2.4 重建 manifest.json（最容易漏的一步）

manifest 按文件**字节数**登记，任何 `ikemen-fs/file/` 下的改动都要重建：

```
node .cache/scripts/rebuild-manifest.mjs
```

规则：递归 `ikemen-fs/file` 全部文件 → 排除 `*.bak*` → key 取相对 `file/` 的路径并把 `\` 换 `/` → 值取字节数 → `{stamp, files}`。**stamp 每次重建递增**（当前 `local38`），并同步更新资产包 `pack.json` 的 `manifestStamp`。

## 3. 验证（入库不算完，跑绿才算）

新建 `.cache/scripts/verify-<角色名>.mjs`，或直接复用 `verify-leona.mjs` 改角色名，两阶段：

| 阶段 | 路径 | 断言 |
|------|------|------|
| A：AI 可打 | `?p1=Rugal2nd&p2=<新角色>&auto=1&ai=4&time=10` | 引擎帧增长 → facebar 出现双方 → 打到结算（localStorage `ikemen-vfs11:save/tf-result.ini` 出现 settled 标志） |
| B：人控对照 | `?p1=<新角色>&p2=Lin&auto=1&ai=0` | 静置 N 帧不变 vs 按键后帧数增长（发键用 Z，别用 Enter=P1 Start 会开暂停菜单） |

运行方式（无头 Edge + CDP，端口任取）：

```
msedge --remote-debugging-port=9391 --user-data-dir=<临时目录> ^
  --disable-background-timer-throttling --disable-backgrounding-occluded-windows ^
  --disable-renderer-backgrounding --no-first-run http://localhost:8100/
node .cache/scripts/verify-leona.mjs .cache/shots-<角色名> 9391
```

已知坑（复现过）：
- **窗口遮挡死锁**：帧冻在某个值不动 = 调试窗口失焦，保持窗口最前（AGENTS.md 机制 3）。
- **旧 localStorage 覆盖层**：行为像旧版本时，换全新 `--user-data-dir` 或清 `ikemen-vfs11:*`。
- facebar 断言注意新 UI 显示中文映射名（如 Leona→莉安娜），脚本断言要兼容。

## 4. 资产集映射登记（进分配池）

角色能跑 ≠ 进了联动分配池。前端 charPool = `mapping.json 的 charPool ∩ 本地已装角色`，所以要双写：

1. **资产包 mapping.json**（`workshops/toon-fighting-web/map_design/<资产集>/mapping.json`）：

```json
{ "charPool": ["Lin", "Hinako", "K'", "Rugal2nd", "Leona"] }
```

2. **角色职业映射**：`角色职业.md` §2 表的「现有引擎角色」列补上，给 story 分配界面提供职业标签（facebar 显示「军人佣兵」即来自这里）。
3. `roster.json` 侧按需给故事 NPC 补 `profession` 字段。
4. `pack.json` 的 `manifestStamp` 同步为最新 stamp。

## 5. 舞台与其他资产

- **舞台**：def + sff 放 `ikemen-fs/file/stages/<id>/`，select.def 里 `[ExtraStages]` 或角色行 `.stage` 后缀引用。现库 9 个 def，默认舞台 `stages/kfm.def`（startEngine 硬编码，换默认舞台要改 index.html）。
- **BGM**：引擎会尝试 `sound/kfm.mid`，缺失只 WARN 不阻塞（日志 `Failed to open BGM` 属正常）。
- **字体**：`font/` 下 fnt，system.def 引用，一般不动。

## 6. 版权红线（不可违反）

- 仓库与资产集**只存角色名引用、职业文案、映射元数据**（pack/story/roster/mapping 四件套可分发）。
- 角色资产本体（sff/snd 等）由使用者按 [下载源.md](./下载源.md) 自行下载，随 APK 私有侧载不分发（对齐 NOTICE.md §5 与 android_h5 口径）。
- 下载源链接只做索引，不在任何对外交付物中转存/直链资产文件。
